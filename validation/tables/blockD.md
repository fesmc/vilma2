## 3-D minus 1Db — the lateral-viscosity signal

1Db is the radial mean **of the same Bagge (2021) field**, so this difference isolates lateral variation rather than mixing it with a change of radial profile.

The 0 ka row is omitted on purpose: `rsl_anomaly` is measured against each run's own present-day field, so at 0 ka it is identically zero for both and the difference carries no information. Present day is covered by the uplift rate below.
